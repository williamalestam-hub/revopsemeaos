Wherever these instructions name one of these values, write it character for character (`<since>` in a query is the value of `since`, without quotes). Never round a time, work one out yourself or write one this command did not print. The times in the documents have the same form, so they compare as text. Never use a Salesforce date word (TODAY, THIS_MONTH, LAST_N_DAYS and the like): Salesforce reads them on a US Pacific clock.
